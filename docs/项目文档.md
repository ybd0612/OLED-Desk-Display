# AI Agent 桌面状态显示器 — 项目文档

## 一、项目概述

基于 ESP8266 + 0.96寸双色 OLED 的桌面小屏幕，通过 USB 串口接收 Python 脚本发来的指令，每次对话结束后显示 Agent 工作摘要。支持中英文显示。

## 设计理念

### 为什么用 AI Agent 总结，而不是用 Hook 自动截取

Hook 脚本只能机械地截取和传递原始文本，没法做语义总结。如果对话内容很长，直接截取的片段往往缺少上下文，看不懂在说什么。

所以采用 **AGENTS.md + conversation_hook.py** 的组合：
- **AGENTS.md** 让 AI 自己理解对话内容，生成精炼的、符合屏幕字数限制的摘要
- **conversation_hook.py** 负责把摘要推送到屏幕

### 为什么要闪屏

直接在屏幕上切换文字，人很容易忽略——尤其是余光扫一眼的时候。所以推送摘要时屏幕会**白黑闪烁 3 次**，确保你能注意到有新消息。

这就是为什么有两个脚本：
- **display_hook.py**：手动控制，直接切换文字，不闪屏（适合主动查看/调试）
- **conversation_hook.py**：AI 对话结束后推送，带闪屏提醒（适合日常使用）

## 四、软件架构

### 4.1 Python 端

**display_hook.py** — 手动控制脚本
- 功能：发送预设状态（WAIT/SUCCESS/FAIL）或自定义文字到屏幕
- 用法：`python display_hook.py WAIT` 或 `python display_hook.py "AI Agent|你好"`
- 依赖：pyserial（`pip install -r requirements.txt`）

**conversation_hook.py** — 对话摘要推送脚本
- 功能：接收对话摘要，推送到屏幕（带闪烁效果）
- 三种使用模式：
  - 手动：`python conversation_hook.py "标题" "第一行" "第二行"`
  - Prompt：`python conversation_hook.py --prompt "对话内容"`（生成让大模型总结的 Prompt）
  - 管道：`echo "对话内容" | python conversation_hook.py --stdin`
- 容量限制：标题最多 10 中文/20 英文，摘要每行最多 10 中文/20 英文，最多 3 行
- 设计理念：不截断不加省略号，直接生成符合屏幕字数限制的完整文字
- 闪烁：发送带 0x1C 前缀，屏幕会白黑闪烁 3 次再显示

### 4.2 Arduino 端：sketch_jun4a.ino

- 位置：`arduino/sketch_jun4a/sketch_jun4a.ino`
- 依赖库：U8g2（Arduino 库管理器安装）
- 字体：u8g2_font_wqy12_t_gb2312（文泉驿中文）
- 模式：enableUTF8Print()（UTF-8 中文支持）
- 分隔符：0x1F 分隔上下区域，0x1E 分隔蓝色区域内多行，0x1C 标记闪烁前缀
- 位图模式：发送 `BITMAP
` 后等待 Arduino 回复 `R`(Ready)，再发送 1024 字节位图数据，完成后回复 `K`(OK) 或 `E`(Error)

### 4.3 Web Canvas 服务

- 位置：`python/web_server.py`
- 功能：启动本地 HTTP 服务(127.0.0.1:8077)，自动打开浏览器
- 画布：128x64 像素，上半黄色下半蓝色双色模拟
- 模式：画笔/橡皮/文字/图片上传
- 协议：文字走原有串口文本协议，画布走位图协议（BITMAP 命令 + 握手）
- Agents 开关：控制 conversation_hook 是否允许推送，状态存在 `python/.agents_enabled` 文件中
- 自动保存：画布内容存 localStorage，文字输入自动保存

### 4.3 字符宽度规则

| 字符类型 | 宽度 | 示例 |
|---------|------|------|
| ASCII（英文/数字/符号） | 1 | `A` = 1, `Hello` = 5 |
| 中文/全角字符 | 2 | `你好` = 4, `AI Agent` = 8 |
| 每行上限 | 20 | 黄色区域和蓝色区域每行都是 20 |

> **重要**：计算字数时必须按宽度计算，不能简单数字符个数。`AI Agent` 是 8 个英文字母但宽度为 8，`你好世界` 是 4 个汉字但宽度为 8。

## 七、配置说明

### 修改串口

编辑 `python/display_hook.py` 和 `python/conversation_hook.py`：

```python
SERIAL_PORT = 'COM3'  # 在 Arduino IDE → 工具 → 端口 中查看
```

### 修改默认文字

编辑 `arduino/sketch_jun4a/sketch_jun4a.ino`：

```cpp
const char* DEF_TOP = "AI Agent";   // 黄色区域默认文字
const char* DEF_BOT = "STANDBY";    // 蓝色区域默认文字
```

### 修改 I2C 引脚

编辑 `arduino/sketch_jun4a/sketch_jun4a.ino`：

```cpp
U8G2_SSD1306_128X64_NONAME_F_SW_I2C u8g2(U8G2_R0, /* clock=*/ 12, /* data=*/ 14, /* reset=*/ U8X8_PIN_NONE);
//                                                                                       ^^^SCL   ^^^SDA
```

## 八、注意事项

- 中文仅支持文泉驿 GB2312 字库中的常用汉字，生僻字可能无法显示
- COM 端口变化时需修改 Python 脚本中的 SERIAL_PORT
- 修改 Arduino 代码后需在 IDE 中重新上传到板子
- 串口被占用时（如 Arduino IDE 串口监视器打开），Python 脚本无法连接
- Arduino IDE 要求 .ino 文件必须在同名文件夹中，所以路径是 `arduino/sketch_jun4a/sketch_jun4a.ino`
