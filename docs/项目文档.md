# AI Agent 桌面状态显示器 — 项目文档

## 一、项目概述

基于 ESP8266 + 0.96寸双色 OLED 的桌面小屏幕，通过 USB 串口接收 Python 脚本发来的指令，实时显示 Agent 工作状态。支持中英文显示。

### 4.1 Python 端




- 依赖：pyserial（`pip install -r requirements.txt`）
- 编码：UTF-8 发送，支持中文






- 容量限制：标题最多 10 中文/20 英文，摘要每行最多 10 中文/20 英文，最多 3 行


- 设计理念：不截断不加省略号，直接生成符合屏幕字数限制的完整文字
- 闪烁：发送带 0x1C 前缀，屏幕会白黑闪烁 3 次再显示

## 八、开发记录

### 修复 1：自定义文本无法显示
- 问题：Arduino 端只有三个固定 if-else，未匹配文本被丢弃
- 解决：增加 else 分支 + showCustom() 函数

### 修复 2：双色屏分区显示
- 改为上黄下蓝双区域独立控制
- 文字自动水平+垂直居中
- 边框 1px 细线

### 修复 3：中文显示支持
- 问题：默认 drawStr() 不支持中文
- 方案：Arduino 端开启 enableUTF8Print()，使用 u8g2.drawUTF8() + getUTF8Width()
- Python 端：UTF-8 编码发送
- 字体：u8g2_font_wqy12_t_gb2312（文泉驿 GB2312 子集）

### 修复 4：默认文字调整
- 上方默认改为 "Ybond"
- 下方默认改为 "STANDBY"

### 修复 5：蓝色区域多行支持
- 蓝色区域支持最多 3 行自动换行
- 按像素宽度智能分行，支持中英文混排
- 多行文字整体垂直居中


- 问题：`\n` 换行符被 readStringUntil 截断，反斜杠与 UTF-8 编码冲突
- 初版方案：用 `~` 波浪号作为蓝色区域内行分隔符
- 最终方案：改用 ASCII 控制字符 0x1E，彻底避免与用户输入冲突（见修复 8）
- Arduino 端新增 drawBySeparator() 函数按分隔符精确分行

### 修复 7：闪烁功能

- 手动发送不闪烁，静默切换
- 实现方式：`drawBox` 填白屏 → `clearBuffer` 黑屏，循环 3 次后重绘文字

### 修复 8：分隔符冲突
- 问题：用户输入内容可能包含 `|`、`~` 等分隔符导致显示错乱
- 方案：改用 ASCII 控制字符作为分隔符，用户不可能手动输入
  - 0x1F (Unit Separator) → 分隔上下区域
  - 0x1E (Record Separator) → 分隔蓝色区域行
  - 0x1C (File Separator) → 标记闪烁前缀


## 九、注意事项

- 中文仅支持文泉驿 GB2312 字库中的常用汉字，生僻字可能无法显示
- COM 端口变化时需修改 Python 脚本中的 SERIAL_PORT
- 修改 Arduino 代码后需在 IDE 中重新上传到板子
- 串口被占用时（如 Arduino IDE 串口监视器打开），Python 脚本无法连接
- Arduino IDE 要求 .ino 文件必须在同名文件夹中，所以路径是 `arduino/sketch_jun4a/sketch_jun4a.ino`
